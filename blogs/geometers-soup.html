Convex Hull Algorithms

Finding the convex hull of a given set of points is a common problem that prevails in many applications is very useful. I can mention an important application of convex hulls in robotics. We often have to find the bounding region of certain shapes given the point cloud of that object. We can create clusters of points by using some clustering algorithm like DBScan and then approximate the shape of the object using the convex hull. I present some of the well know convex hull algorithms for 2D point sets some which can be easily extended to higher dimensions.
